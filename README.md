# PayGuard - Secure Digital Wallet System

## 🚀 Overview
A backend banking architecture built with **Node.js** and **PostgreSQL**.
This project implements **ACID-compliant transactions** to ensure data integrity during fund transfers.

## 🛠️ Tech Stack
* **Runtime:** Node.js (Express.js)
* **Database:** PostgreSQL (Relational Data & Transactions)
* **Security:** UUIDs, Row-Level Locking
* **Tools:** Postman, Git
